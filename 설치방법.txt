삽화가 (개인용) / LV-Illust — 설치 방법
====================================================
※ 개인용입니다. 다른 사람에게 주거나 GitHub 등에 올리지 마세요. 이 저장소는 로컬 전용입니다
  (git init만 했고 push·원격 저장소 없음).

이 확장이 하는 일
- 캐릭터 카드마다 "인물 외형 등록부"를 둡니다(이름 여러 개 + 외형 프롬프트 + 켜기/끄기).
- AI가 답변 속에 <pic chars="이름1, 이름2" prompt="장면 묘사"> 태그를 쓰면, 그 자리에
  NovelAI 그림을 넣습니다. 등록된 이름이면 등록한 외형을 인물 칸(NAI characterTags)에 씁니다.
- 입력창 버튼 '삽화가 설정'에서 설정(지시 위치/깊이/역할/답변당 최대 그림)·등록부·
  이 채팅 자동생성 on/off·그림 목록(다시 그리기)을 관리합니다.
- 자동 생성은 기본 켜짐, 채팅별로 끌 수 있습니다.
- 그림을 그리는 도중에 그 메시지를 고치거나 스와이프하면, 그림은 그 메시지에 넣지 않고
  "넣지 못함" 상태로 같은 패널 목록에 남습니다(자동 재시도 없음, 그림 자체는 버려지지 않음).

1. 빌드 확인 (이 폴더에서, 설치 전에 매번)
   node scripts/build.mjs
   node --test test/*.test.mjs
   두 dist 파일이 바뀌었으면 git status로 확인하고 커밋하세요.

2. 컨테이너로 복사
   컨테이너 이름이 lumiverse라고 가정합니다. 아래는 당신이 직접 실행하는 명령입니다
   (이 에이전트는 실행하지 않습니다 — "설치는 제가 합니다"에 따름).

     docker exec lumiverse mkdir -p /app/data/extensions/lv_illust
     docker exec lumiverse sh -c 'rm -rf /app/data/extensions/lv_illust/repo.prev && \
       mv /app/data/extensions/lv_illust/repo /app/data/extensions/lv_illust/repo.prev 2>/dev/null; true'
     docker cp -q . lumiverse:/app/data/extensions/lv_illust/repo
     docker exec -u 0 lumiverse chown -R bun:bun /app/data/extensions/lv_illust

   (.git 폴더가 함께 복사되어도 무방합니다 — DnH 메뉴 확장과 같은 방식입니다.)

3. 불러오기 (서버 주인 계정으로)
   루미버스에 owner로 로그인 → 왼쪽 패널 Extensions(Spindle) → 'Import Local'.
   목록에 '삽화가 (개인용)'이 꺼진 상태로 나타납니다.

4. 권한 켜기 (전부 admin 승인 필요한 privileged 권한)
   - image_gen    : 그림 생성 (spindle.imageGen.generate)
   - interceptor  : 답변 전 지시문 끼워넣기 + 과거 그림을 짧은 요약으로 바꿔 보내기
   - chat_mutation: 메시지 읽기/고치기 (그림을 태그 자리에 넣기)
   - characters   : 카드별 인물 등록부 저장
   - chats        : 채팅이 속한 카드 찾기 (등록부를 그 카드 것으로 불러오기 위해)
   - generation    : GENERATION_ENDED 구독(답변 완료 감지) — spindle.on 자체가 이 권한으로 막혀 있습니다

5. 켜기
   '삽화가 (개인용)'을 Enable 합니다. 새로고침하면 입력창에 '삽화가 설정' 버튼이 보입니다.

6. 써 보기 전 꼭 확인할 것 (docs/API-NOTES.md 참고)
   등록부에 인물 하나를 등록하고(이름 1개 이상, 외형 프롬프트), 그 카드의 채팅에서 AI가
   <pic ...> 태그를 쓰게 유도한 뒤(지시문은 자동으로 들어갑니다), 실제로 그림이 화면에
   보이는지 확인하세요. 마크다운 이미지 문법(![그림:id|요약](url))이 루미버스 화면에서
   그림으로 렌더링되는지는 이 세션에서 실행해 확인하지 못했습니다 — 안 보이면 평문으로
   남을 수 있고, 그 경우 src/core.mjs의 renderSuccessMarker()만 고치면 됩니다(핵심 로직은
   그대로 두고 화면 표기만 바꾸는 수준).

업데이트할 때
   src를 고친 뒤 node scripts/build.mjs → node --test test/*.test.mjs → 통과하면
   2번 복사 단계를 다시 실행하고, Extensions에서 '삽화가 (개인용)' Restart(또는
   Disable→Enable) 후 새로고침하세요.
