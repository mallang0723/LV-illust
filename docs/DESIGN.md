# LV-AutoPic 설계안 (초안 v0.1, 2026-10-21)

루미버스(Lumiverse)용 개인 확장. AI가 답변 안에 그림 태그를 쓰면 그 자리에 NovelAI 그림을 넣고,
**인물별로 등록한 외형 프롬프트를 이름으로 찾아** NAI 캐릭터 프롬프트 칸에 넣는다.

## 0. 원칙

- **클린룸.** SillyGgu/AutoPic은 라이선스가 없다. 동작과 화면만 참고하고 코드는 보지도 옮기지도 않는다
  (태그 형식, 설정 항목 이름 같은 *관찰 가능한 동작*만 참고).
- **비공개 개인용.** 저장소는 private, 공개 배포 안 함.
- **루미버스 기본 기능과 겹치지 않기.** 메인·그림체 프롬프트, 카드 단위 캐릭터 프리셋, 장면 자동 생성, 갤러리는
  루미버스 기본 기능을 쓴다. 이 확장은 기본에 없는 것만 한다:
  1. 답변 속 그림 태그 → 그 자리에 그림
  2. 인물별 외형 등록 + 이름 매칭
- **그림은 사용자의 NovelAI 연결로 그린다** (`spindle.imageGen.generate`). 지금 설정에서는 그 연결이
  SharedNAI 사이드카로 가므로 따로 처리할 것 없음.

## 1. 기능 범위

### 1단계 (MVP)
| # | 기능 | 설명 |
|---|---|---|
| F1 | 태그 지시 끼워 넣기 | "그림이 필요한 장면에 `<pic>` 태그를 써라"는 지시를 프롬프트에 넣는다. 위치·깊이·역할 설정 가능. 확장을 끄면 지시도 빠짐 |
| F2 | 태그 감지 → 생성 | 생성이 끝나면(`GENERATION_ENDED`) 답변에서 태그를 찾아 하나씩 그린다. 한 답변에 여러 장 가능(상한 설정) |
| F3 | 이름 매칭 | 태그 안 인물 이름을 등록 목록에서 찾아 외형 프롬프트로 바꾸고 NAI 인물별 칸(`characterTags`)으로 보낸다 |
| F4 | 인물 외형 등록부 | 인물마다 이름 여러 개(별칭), 외형 프롬프트, 켜기/끄기. **카드 단위 저장**(같은 카드의 모든 채팅에서 공유) |
| F5 | 그림 넣기 | 태그 자리를 그림으로 바꿔 메시지에 넣는다(`chat.updateMessage`). 실패하면 태그 자리에 "다시 그리기" 표시 |
| F6 | 다시 그리기 | 그림 아래 버튼으로 같은 프롬프트 재생성 |

### 2단계 (나중에, 필요하면)
- 고정 이미지 슬롯, 새 메시지로 넣기 같은 다른 삽입 방식
- NAI PNG 메타데이터에서 외형·설정 가져오기
- 수동 생성 창 (태그 없이 직접 그리기)
- 루미버스 Scene tool 결과에 등록 외형 덮어쓰기 (확장이 그 단계에 끼어들 수 있는지 먼저 확인 필요)

### 안 하는 것
- 캐릭터 카드 단위 프롬프트 저장 (루미버스 Character preset이 이미 함)
- 그림체 프리셋 관리 (루미버스 프롬프트 프리셋 사용)
- 미리 깔아 둔 인물 목록 (등록부는 비어서 시작)

## 2. 이름 매칭 규칙

**한국어 채팅이든 영어 채팅이든 이름을 바꿔 쓸 필요 없음.** 인물 하나에 이름을 여러 개 등록하고, 그중 아무거나 맞으면 같은 인물로 본다.

```
인물: 아드리안
  이름들: 아드리안 / Adrian / 아드리안 폰 아이젠베르크 / Adrian von Eisenberg / 마에스트로
  외형: 1boy, ...
  사용: 켜짐
```

- 비교할 때 대소문자, 앞뒤 공백, 가운데 공백 차이는 무시한다.
- 긴 이름부터 맞춘다. "아드리안 폰 아이젠베르크"가 "아드리안"보다 먼저.
- 등록 안 된 이름은 그대로 둔다. 그 인물은 AI가 쓴 묘사만으로 그린다.
- 꺼 둔 인물은 매칭은 되지만 외형을 넣지 않는다(AI 묘사만 사용).
- AI 지시에 등록된 인물 이름 목록을 같이 넣어서, AI가 등록된 이름 그대로 쓰도록 유도한다.
  이때 채팅 언어와 상관없이 **어느 별칭이든 인식**하므로 AI가 번역해서 써도 맞는다.

## 3. 태그 형식

```
<pic chars="아드리안, 정수빈" prompt="장면 묘사 태그들">
```

- `prompt`: 장면·구도·배경 (NAI base prompt로)
- `chars`: 등장 인물 이름. 쉼표로 구분, 최대 6명 (V4/V4.5 기준. V5는 더 가능하지만 기본 6)
- 인물별 동작·표정이 필요하면 `chars="아드리안: smirking, arms crossed; 정수빈: looking away"` 형식 허용
  → 등록 외형 + 동작을 합쳐 그 인물 칸에 넣음
- 형식이 깨진 태그는 그리지 않고 표시만 남긴다(조용히 무시하지 않기).

## 4. 생성 흐름

```
GENERATION_ENDED (assistant 메시지)
  → 메시지 본문에서 <pic …> 찾기 (없으면 끝)
  → 태그마다:
       chars 파싱 → 등록부에서 이름 매칭 → characterTags = [{tags: 외형 + 동작}, …]
       prompt = 메인 프롬프트(루미버스 프리셋 또는 확장 설정) + 태그 prompt
       spindle.imageGen.generate({ prompt, negativePrompt, parameters:{ characterTags },
                                   owner_chat_id, owner_character_id, includeDataUrl:false })
       → imageUrl 받기
  → 메시지 본문의 태그를 그림 표시로 교체 (chat.updateMessage)
       원래 태그 정보는 메시지 메타데이터에 보관 (다시 그리기·스와이프용)
```

- 스와이프·재생성: 새 답변 기준으로 다시 처리. 이전 스와이프 그림은 그 스와이프에 남음.
- 메시지를 수정해서 태그를 새로 쓰면 다시 그림(`MESSAGE_EDITED`).
- 동시 생성 1개(SharedNAI 한도), 큐로 순서대로.
- AI 프롬프트에 그림 표시가 그대로 들어가지 않게, 다음 턴부터는 그림 자리를 짧은 표시(`[그림: 장면 요약]`)로
  바꿔 보내는 프롬프트 정리 규칙을 같이 둔다.

## 5. 저장 위치

| 데이터 | 저장 단위 | 비고 |
|---|---|---|
| 인물 외형 등록부 | 캐릭터 카드별 | 같은 카드의 모든 채팅 공유 |
| 확장 설정 (지시 위치·깊이·상한 등) | 사용자 전체 | |
| 태그 원본·생성 결과 | 메시지 메타데이터 | 다시 그리기용 |

## 6. 루미버스 API 근거 (확인 상태)

| 필요한 것 | API | 상태 |
|---|---|---|
| 그림 생성 | `spindle.imageGen.generate` (ImageGenRequestDTO) | 타입 정의 확인 |
| NAI 인물별 칸 | `parameters.characterTags: [{tags}]` → `characterPrompts`·`v4_prompt.char_captions` | 루미버스 NovelAI 공급자 코드·테스트 확인. 위치 지정(center)은 고정 0,0 |
| 생성 끝 이벤트 | `GENERATION_ENDED` | 타입 정의 확인 |
| 메시지 고치기 | `spindle.chat.updateMessage` | 타입 정의 확인, 실제 동작 미시험 |
| 지시 끼워 넣기 | 생성 인터셉터 | 타입 정의 확인, 실제 동작 미시험 |
| 확장 UI | 패널·버튼 | D&H 메뉴 확장에서 동작 확인됨 |
| SharedNAI 경로 인물 칸 | 사이드카 `/ai/generate-image` | V4.5·V5 인물 프롬프트 지원은 SharedNAI 쪽 한도 내(V3/V4/V4.5 6명, V5 32명) |

**만들기 전 첫 작업:** 위 "미시험" 항목을 최소 확장으로 실제 확인한다(메시지 고치기, 인터셉터, 인물 칸 2명 그림).

## 7. 테스트

- 단위: 태그 파싱(깨진 형식 포함), 이름 매칭(별칭·긴 이름 우선·대소문자·꺼진 인물), 프롬프트 조립
- 통합: 가짜 imageGen으로 GENERATION_ENDED → updateMessage 흐름
- 실제: 우리 루미버스에서 2인 장면 1장, 3장 연속, 스와이프, 메시지 수정
- 확장 배포 전 Codex 검토

## 8. 정할 것 (사용자 확인)

1. 그림 표시 방식: 본문 속 그림(태그 자리) — 기본안. 다른 방식 필요 여부
2. 한 답변당 최대 그림 수 기본값 (제안: 2)
3. 자동 생성 기본 켜짐/꺼짐 (제안: 켜짐, 채팅별로 끌 수 있게)
4. 메인 프롬프트를 루미버스 이미지 프리셋에서 가져올지, 확장 설정에 따로 둘지 (제안: 루미버스 프리셋 사용)
